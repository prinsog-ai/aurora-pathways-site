What It Does

Forekast lets anyone create a prediction market and anyone else trade on it. Create a market: "Will BTC hit $150K by December?" Buy YES tokens if you believe it. Buy NO tokens if you don't. When the event resolves, the contract pays winners automatically.

No central authority decides the outcome. Multiple independent oracles report the result. The contract enforces the rules. If someone tries to manipulate the outcome, they'd have to corrupt multiple independent data sources — not just one platform's admin panel.

Multi-Oracle Resolution

Forekast uses multiple oracle providers to resolve each market. A single oracle could be wrong or compromised. Three oracles must agree — if they don't, the market escalates to community vote. No single point of failure. No single point of corruption.

How It Works

Create a market. Define the question, the resolution date, and stake the initial liquidity. The contract mints YES and NO tokens at equal value.

Trade. Anyone can buy YES or NO tokens. Prices move based on demand — a live prediction of probability, priced by the market, not by an analyst.

Resolve. When the event date arrives, multiple oracles report the outcome. If consensus is reached, the contract distributes winnings. If not, the market escalates to community resolution.
